# Правила работы с репозиторием

После реализации новой функции или исправления и успешного прохождения всех
относящихся к изменению тестов сразу создавай коммит и выполняй `git push`.
Не жди отдельной просьбы или подтверждения пользователя на commit и push.
Включай в коммит изменения текущей задачи; остальные правки добавляй только
по явному указанию пользователя. Для изменений только в документации достаточно
проверить содержимое и выполнить `git diff --check` перед commit и push.
